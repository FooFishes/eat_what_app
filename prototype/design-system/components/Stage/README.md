# Stage

有主角菜的页面顶部那块彩色区域：菜名、店名、价格和按钮放在左边，主菜盘子从右侧出血。

**调用方提供**：舞台色（9 个 `stage-*` 之一，连同它的文字色）、已经断好行的菜名（每行不超过四个字，最多三行）、店名、距离、价格、主图（一个 `DishPlate`）、两个动作。

**规格**
- 高度 `size-stage`（520px，对应 844 高的屏幕），白色 `Sheet` 从舞台底部往上压 32px。
- 舞台随屏幕高度伸缩：矮屏按比例缩小，最矮 420px，盘子和转盘跟着缩；高屏最高 560px，多出来的给抽屉。菜名、价格和按钮贴着舞台底部排，不被抽屉盖住。
- 左栏文字区宽 160–200px，避开盘子；菜名 `stage-dish`，排到三行时缩小字号，不省略；价格 `price-hero` 放在左栏底部。
- 主图盘子外框 `size-plate`（320px），圆心大约在 (318, 300)，右侧出血约 90px。
- 浅色舞台文字用 `ink`、次级文字用 `ink-soft`；深色舞台文字和次级文字都用 `paper`（次级降到 85% 不透明）。
- 按钮行：左边次按钮（`stage-ghost-*` 底），右边实心按钮（底色 = 舞台文字色，文字 = 舞台色），各占一半，间距 `space-10`。
- 换菜时背景色、文字色 500ms 一起过渡。

**要做**
- 首页舞台下面叠一个 `Turntable`，让旁边的菜从左下角露出一点。
- 菜品详情、发布第 2 步、「我的」也用同一个舞台，只是内容不同。

**不要**
- 在舞台上放列表、第三个按钮或成段文字。
- 用 `stage-*` 以外的颜色，或者直接用照片的平均色。
- 把文字压在盘子上。
