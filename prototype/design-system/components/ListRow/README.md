# ListRow

没有卡片的列表行：左边缩略图或头像，中间两到三行文字，右边一个可选的动作或缩略图；行与行之间只靠留白分开。

**调用方提供**：缩略图或头像、标题、次级信息、可选右侧内容（缩略图、时间、按钮）、是否未读、点击去向。

**变体**
- 店铺行（附近列表）：64px 缩略图（`radius-thumb-lg`）；标题 `row-title`；第二行距离 `distance` 加商圈 `meta`；第三行「招牌：鲜虾蟹籽云吞」。
- 菜品行（足迹、我的评论）：56px 缩略图；标题菜名 `row-title`，第二行店名或我说的话 `meta`；右边时间 `caption`。
- 消息行：44px 圆头像（名字首字，底色取一个 `stage-*`，文字按它的深浅）；正文 `body`，人名加粗；时间 `caption`；右边是相关菜品的 48px 缩略图，或者「回关」这类按钮。未读时行首放 7px `ink` 圆点。

**规则**
- 左右边距 `space-20`，缩略图和文字之间 `space-14`，行与行之间 16–20px。
- 整行可点时整行是一个链接，右侧的按钮单独可点。
- 一组列表按时间或类别分组时，组标题用 13px 600 `ink-muted`（「今天」「本周」「主食」）。

**不要**
- 给每一行加背景、圆角或分隔线。
- 在一行里放两个以上的可点元素。
